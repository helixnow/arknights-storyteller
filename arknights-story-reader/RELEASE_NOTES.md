# 明日方舟剧情阅读器 2.0.0 发布说明

## 本轮改造

- 合并阅读器、搜索、同步、人物素材、应用壳等收尾改造，作为 2.0.0 正式版。
- 修复切换页面后各 KeepAlive 面板叠在同一视口里抢渲染的问题：后台面板改为跳过整棵子树绘制。
- 去掉 tab 包装层 isolate，避免同步框被底栏盖住并可点穿切走。
- 滚动快照改为按事件目标记账，避免长列表每帧扫树；首页跳收藏的归顶不再被快照盖回。
- 搜索取消后不再被防抖自动搜复活；同步/导入成功后版本查询不再占住任务锁。
- Android 更新清单改为原生层拉取，避开 GitHub Releases 的 CORS 拦截。
- 将应用版本统一升级至 `2.0.0`，覆盖 npm、Tauri 与 Cargo 的清单及锁文件。

## 发布工程

- Android 构建环境固定安装 API 36 平台和 Build Tools 36.0.0。
- 正式发布必须使用有效的 release keystore，不再回退 debug 签名。
- 发布工作流使用仓库已提交的版本，创建 Release 时绑定当前提交 SHA。
